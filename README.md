# 月の軌道モデル (Moon Orbit Model)

太陽、地球、月の軌道の関係を視覚的に理解するためのシンプルなWebアプリケーションです。
外部ライブラリを一切使用せず、ブラウザでHTMLファイルを開くだけで動作します。

## 概要
本来の天体の動きはスケールや周期が極めて大きく、頭の中だけでその軌跡を直感的に捉えるのは困難です。
このモデルでは、数学や理科の天体分野に苦手意識を持つ生徒さんでも「どのような軌道を描いて進んでいるのか」を直感的にイメージしやすいように、あえて公転周期をデフォルメ（地球が太陽を1周する間に、月が地球を15周する設定）しています。

元々はGeoGebraで作成した軌道モデルをベースとしており、教育現場等でより手軽に配布・操作ができるよう、1枚のHTMLファイル（Canvas API）として再実装しました。

## 主な機能
* **天体アニメーション**: 太陽を中心に公転する地球と、地球を中心に公転する月の動きを、実際の天体と同じ「反時計回り」でシミュレーションします。
* **軌跡の可視化**: 月が宇宙空間に描く、花びらのような「波打つ軌跡」を事前に計算して背景に描画します。
* **軌道の表示/非表示の切り替え**: 軌跡の線を消して天体の動きそのものに集中したり、線を表示して数学的な曲線を観察したりと、学習の目的に合わせた切り替えが可能です。
* **再生 / 一時停止**: アニメーションを任意のタイミングで止めて、天体の位置関係をじっくり観察できます。

## 使い方
1. 本リポジトリから `index.html` をダウンロードします。
2. お使いのWebブラウザ（Google Chrome, Microsoft Edge, Safariなど）で `index.html` をダブルクリックして開きます。
※ Webサーバー等の環境構築は一切不要です。

## カスタマイズについて
ソースコード内の定数を変更することで、天体のサイズや距離、公転周期などを簡単に調整できます。授業の進行や見せたいモデルに合わせてカスタマイズしてください。

```javascript
// index.html 内の以下の数値を変更してカスタマイズ可能
const earthOrbitRadius = 260; // 太陽から地球までの距離
const moonOrbitRadius = 12.5; // 地球から月までの距離
const earthPeriod = 30;       // 地球の公転周期
const moonPeriod = 1;         // 月の公転周期
